# Taller Programación 2

Este proyecto fue realizado como parte del taller de Programación 2.  
El objetivo principal es practicar la creación de clases en Java, el uso de atributos, constructores, métodos, objetos y clases de prueba.

## Descripción del proyecto

El proyecto contiene varios ejercicios desarrollados en Java. Cada ejercicio tiene una clase principal y una clase de prueba para comprobar su funcionamiento.

En este taller se trabajó con los siguientes temas:

- Creación de clases en Java.
- Uso de atributos y métodos.
- Constructores.
- Métodos `get` y `set`.
- Creación de objetos.
- Uso de clases de prueba.
- Cálculos básicos con datos ingresados o definidos.
- Organización de archivos dentro de un proyecto Java.
